## MicroParquet v1.14.0

Everything since v1.8.0: the linked model (Phase 9), dashboards and reports (Phase 10), the one-window redesign, planning and forecasting (Phases 11 to 13) and the offline assistant (Phase 14). 1,400+ automated tests.

### New in this release

**One window, four views.** Report, Dashboard, Data and Model, with a rail to switch between them, a collapsible side panel and an empty-screen hint that says what to do next.

**The model (Phase 9).**
- Link tabs like tables of a database (branch, product and GL masters, keys of two columns), with a key check that lists duplicate, blank and unmatched keys so they can be fixed at source.
- One shared calendar and an as-of date (defaults to the latest data date).
- Balances and flows done correctly: closing, opening and average daily balance (month-end-only data gets a labelled average), MTD / QTD / YTD, prior period and same period last year (same days or full period).
- Named measures and ratios (CASA ratio, ADR, yield, cost of funds, NIM) with Act/365, Act/360 or Act/Act.
- Pop-out pivot builder and an Excel-style nested pivot layout next to the side-by-side one.

**Dashboards and reports (Phase 10).** Dashboard pages with charts, pivots, KPI cards, text and images; page filters, cross-filtering and drill; a fixed grid or free layout; imported page designs; export to an interactive HTML report (with a small-file option for email), PowerPoint with real editable charts, and PDF pages.

**Planning and analysis (Phases 11 to 13).**
- File-open dialog: keep or drop columns, and reverse a sign (advances that arrive negative).
- Variance bridge (volume, mix and rate that add up exactly) and top movers.
- Budget and target tables: plan, actual less plan, % achieved; target bands with red/amber/green zones, bullet and gauge visuals.
- Rolling 3 and 12 month windows and moving averages.
- Forecasting: trend + seasonality, Holt-Winters, growth / run-off and ARIMA, with an automatic back-test, 80% and 95% bands, outlier handling and manual adjustments; what-if scenarios, always labelled as not actual.
- Drill-through from KPI cards, pivot cells and dashboard items; saved views of a dashboard page's filters (optionally following the latest period); numbered chart notes that travel into PDF, HTML, Excel and PowerPoint.

**Assistant (Phase 14).** A panel in every view (the Ask button, Help ▸ Assistant or F1) that answers from the guide book built into the program and names the section it used. It never calculates numbers. Optional: copy a small GGUF model and the llama.cpp `llama-server` into `portable_data\assistant\` once, and it phrases the answers locally (loopback only; no data file is ever sent to it). See `docs/guide/assistant.md`.

**Guide book.** Twelve new notes for the planning and analysis tools, and a note for the assistant.

### Fixes
- A race that could make `JobQueue.wait_idle` report idle for an instant before a queued job started.

### Download
- Windows 10/11 (x64): `MicroParquet-Windows-x64-Portable.zip`. Unzip anywhere and run `MicroParquet.exe`.
- macOS (Apple Silicon): `MicroParquet-macOS-AppleSilicon-App.zip`. Right-click ▸ Open the first time.

Keep your `portable_data` folder when you replace the program; it holds your settings, schemas, rule files and saved runs.
